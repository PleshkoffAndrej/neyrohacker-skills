# Справочник типов контента

Тип контента — универсальная рекомендация: она работает у любого пользователя, независимо от того, какие скиллы у него установлены.

## Правило выбора

Тип вытекает из **природы идеи**, а не из привычки. Проверь по порядку:

1. **Есть ли что показать глазами?** Динамика, до/после, физическое действие → Reels/Shorts. Нечего показывать — не предлагай видео, это главная ошибка.
2. **Тема живёт год или сгорит за неделю?** Живёт и её ищут в поиске → лонгрид. Сгорит → пост.
3. **Это список или пошаговый разбор?** 5–9 равных пунктов → карусель или тред.
4. **Нужно ли доказательство?** Есть цифры, скрины, кейс → лонгрид или карусель. Голое мнение → пост.
5. **Сколько мыслей в идее?** Одна → пост. Больше трёх — не ужимай, бери длинный формат или атомизируй.

Всегда называй **одну альтернативу** и **один неподходящий тип** с причиной — это экономит автору неудачную попытку.

## Типы

| Тип | Когда берём | Объём | Скелет |
|-----|-------------|-------|--------|
| **Пост в Telegram** | Одна мысль, есть мнение или приём, актуально сейчас | 800–2000 знаков | Крючок → тело 3–6 абзацев → один CTA → хэштеги |
| **Карусель** | 5–9 равных пунктов, чек-лист, фреймворк — то, что сохраняют | 6–10 слайдов | Слайд-хук ≤6 слов → слайды по одной мысли → слайд-CTA → подпись |
| **Reels / Shorts** | Есть визуальная динамика, показ действия, эмоция | 30–45 сек | Крючок 3 сек (что видно + что слышно) → 5–8 кадров → титры → CTA |
| **Тред** | Развёрнутая аргументация, разбор по шагам, спор | 5–9 твитов | Хук-твит → тезисы по одному на твит → вывод → CTA |
| **Лонгрид / SEO-статья** | Тему ищут в поиске, есть фактура и первоисточники, живёт год+ | 5–10 тыс. знаков | H1 → быстрый ответ → разделы с прямым ответом в начале → выводы → источники |
| **Видео с аватаром** | Нужно лицо и голос, но не нужна съёмка: объяснение, анонс | 60–90 сек | Хук → основа → призыв + визуальный ряд отдельно |
| **Выпуск подкаста** | Тема требует разговора, есть спор или гость | 20–40 мин | Заход → 3–5 блоков → выводы → анонс следующего |
| **Рассылка** | Обращение к своей базе, есть личная позиция или новость продукта | 2–4 тыс. знаков | Тема письма → личный заход → польза → одно действие |
| **Интерактивный гайд** | Материал, к которому возвращаются: инструкция, набор промптов | от 10 тыс. знаков | Обложка → оглавление → блоки Q&A → врезки промптов |
| **Mind map** | Материал сложный по структуре, важны связи, а не текст | 3–5 уровней | Центр → ветви → листья |
| **Песня / джингл** | Событие, поздравление, вирусная шутка, гимн сообщества | 1–2 мин | Куплет → припев → бридж |

## Матрица «природа идеи → тип»

| Природа идеи | Первый выбор | Альтернатива | Мимо |
|--------------|--------------|--------------|------|
| Свежая новость с твоим мнением | пост | тред | лонгрид (устареет) |
| Пошаговая инструкция | карусель | лонгрид | Reels (не влезет) |
| Разбор инструмента с цифрами | лонгрид | карусель | пост (жалко фактуру) |
| Личная история, провал, урок | пост | Reels | карусель (сушит) |
| Спорный тезис | тред | пост | гайд |
| Подборка ресурсов | карусель | лонгрид | Reels |
| Показ работы инструмента | Reels | видео с аватаром | тред (нечего читать) |
| Большая тема с фактурой | лонгрид | атомизация в серию | пост |
| Набор промптов | интерактивный гайд | карусель | тред |
| Анонс события | пост | рассылка | лонгрид |

## Связка со скиллами сессии

Посмотри, какие скиллы доступны в текущей сессии, и сопоставь по смыслу их описаний с типом контента. Совпало — допиши в шифровку строку «→ передай в `имя-скилла`». Не совпало — оставь только тип.

Правила:
- Имена скиллов бери **только из списка доступных в этой сессии**. Выдуманное имя ломает работу пользователя.
- Один тип — один скилл. Не предлагай три варианта на выбор.
- У пользователя без скиллов шифровка обязана работать сама по себе: тип контента, скелет и сырьё в ней уже есть.
