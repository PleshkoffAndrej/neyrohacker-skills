# Режим 4: КОНЦЕПТ

Штурм заканчивается файлом. Разговор без файла через неделю превращается в «мы вроде что-то решили».

Файл: `Концепты/<слаг>.md` в рабочей папке.

## Формат

```markdown
# Концепт: <название идеи>

**Дата:** <дата> · **Статус:** черновик / принят / отложен / закрыт
**Оценка штурма:** <сумма> из 25

## Результат
<что изменится — состоянием, а не действием>

## Критерий успеха
<по какому признаку увидим, что получилось>

## Провал
<что считаем провалом>

## Суть
<2–4 строки: что делаем и в чём соль>

## Адресат
<кому и насколько остро болит>

## Рассмотренные варианты

| Вариант | Эффект | Стоимость | Уверенность | Сумма |
|---------|--------|-----------|-------------|-------|
| A. <…> | | | | |
| B. <…> | | | | |
| Ничего не делать | | | | |

**Выбран:** <вариант> — <одна строка почему>

## Отвергнуто и почему

- **<вариант>** — <причина отказа>
- **<вариант>** — <причина отказа>

## Разбор по осям

| Ось | Оценка | Слабое место | Усиление |
|-----|--------|--------------|----------|

**Было <N> → стало <M> после усилений.**

## Допущения

<то, что пользователь не подтвердил, а Штурм принял на веру. Проверить перед стартом>

## Что дальше

1. <первый шаг, конкретный>
2. <второй>

**Передать:** <кому — скилл из сессии или человеку>
```

## Про раздел «Отвергнуто»

Самая ценная часть файла. Решения помнятся, причины отказов — нет: через месяц те же варианты всплывают заново, и круг повторяется.

Пиши причину, а не оценку: не «слабый вариант», а «требует поддержки каждую неделю, которой не будет». Причина стареет медленнее вердикта — условия меняются, и отвергнутый вариант иногда становится рабочим. Тогда видно, что именно изменилось.

## Передача по цепочке

Концепт — общий конверт команды. В конце укажи получателя:

| Что за замысел | Кому |
|----------------|------|
| Новый скилл или доработка существующего | `neyrina` — берёт «Результат», «Критерий успеха» и «Провал» как готовый Шаг 1 |
| Выступление, вебинар, доклад | `sufler` — берёт те же поля как бриф выступления |
| Контентная идея, нужны источники и сырьё | `ideolog` |
| Всё остальное | человеку, в работу |

Имена скиллов бери **только из доступных в этой сессии**: выдуманное имя ломает цепочку. Подходящего нет — скажи прямо: «в сессии некому передать, концепт на руках».

Предложи запуск следующего скилла, но не запускай без ответа: «Отдаю Нейрине? Она возьмёт результат и критерий из концепта и не будет спрашивать заново».

## Короткий штурм

Пользователь просит быстро глянуть идею — не тащи его через все четыре режима. Минимальный концепт: результат, оценка по осям одной таблицей, две-три строки усилений, получатель. Пять минут вместо получаса, файл всё равно остаётся.
